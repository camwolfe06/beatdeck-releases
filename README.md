# BeatDeck releases

Installers for **BeatDeck**, a Spotify-aware music visualizer for Windows.

This repository only holds the installers (`BeatDeck-Setup-<version>.exe`) and the
`latest.yml` update feed. Installed copies of BeatDeck check here and update
themselves in the background when nothing is playing. The source code lives in a
private repository.

To install: download the newest `BeatDeck-Setup-<version>.exe` from
[Releases](../../releases/latest) and run it. Windows may warn that the app is
unsigned: click **More info → Run anyway**.

Signing in to Spotify only works for accounts the owner has added to the app's
allowlist.
